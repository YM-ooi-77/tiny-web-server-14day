└── webserver.cpp      # WebServer类，封装事件循环、IO、业务


线程模型（线程池 + 生产者-消费者）
1. 主线程：bind/listen → epoll_wait → accept → push(conn_fd) 到任务队列  
2. 工作线程池（默认 8 线程）：while(true) pop(conn_fd) → read/parse → 业务 → write → close  
3. 任务队列：线程安全队列（mutex + cond_var），主线程写，worker 读


类关系
核心类关系（裸指针 + 手动管理）

WebServer
├── ThreadPool* m_pool        // 线程池
├── Epoll*      m_epoll       //  IO 多路复用
├── Timer*      m_timer       // 定时器
└── Log*        m_log         // 日志

ThreadPool
└── 任务队列<function<void()>>  // 存 std::bind(&WebServer::deal_with_http, ...)

HttpConn（每个连接 new/delete）
├── int m_sockfd               // 已连接套接字
├── Epoll* m_epoll             // 注册/修改事件
└── 请求缓冲区 + 解析状态机    // 读-解析-生成响应

Epoll
└── int m_epollfd              // epoll_create 返回值

Timer
└── 小根堆<HttpConn*>         // 按过期时间排序，踢非活跃连接
